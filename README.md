# Question and Answer REST API

โปรเจกต์ REST API สำหรับระบบถาม–ตอบ พัฒนาด้วย Node.js, Express.js และ PostgreSQL โดยรับคำขอจากผู้ใช้งานผ่าน HTTP ตรวจสอบความถูกต้องของข้อมูลด้วย middleware และติดต่อฐานข้อมูล PostgreSQL เพื่อจัดเก็บหรือเรียกดูข้อมูล ก่อนส่งผลลัพธ์กลับในรูปแบบ JSON

ระบบรองรับการทำงานดังนี้

- สร้าง ดู แก้ไข และลบคำถาม
- ค้นหาคำถามจากชื่อเรื่องหรือหมวดหมู่
- เพิ่มและดูคำตอบของแต่ละคำถาม
- ลบคำตอบทั้งหมดที่อยู่ภายใต้คำถามที่กำหนด
- โหวตคำถามและคำตอบด้วยคะแนนบวกหรือลบ
- ตรวจสอบข้อมูลคำถาม คำตอบ และคะแนนโหวตก่อนดำเนินการ
- ตรวจสอบว่าคำถามหรือคำตอบที่อ้างอิงมีอยู่จริง
- ลบข้อมูลคำตอบและคะแนนโหวตที่เกี่ยวข้องโดยอัตโนมัติเมื่อลบคำถาม

โครงสร้างของระบบแยกส่วน route สำหรับจัดการคำถามและคำตอบออกจาก middleware ที่ใช้ตรวจสอบข้อมูล ส่วนการเชื่อมต่อและเรียกใช้ฐานข้อมูลถูกรวมไว้ในโมดูลแยกต่างหาก ทำให้โค้ดเป็นระเบียบและดูแลรักษาได้ง่าย
